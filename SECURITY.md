# Security

This project bridges USB/Bluetooth HID to vintage Apple Desktop Bus hardware for hobby and preservation use.

- Please **do not** file public issues that include secrets, proprietary dumps you cannot share, or personal data from paired devices beyond what is needed to debug.
- For sensitive reports, open a private GitHub security advisory if available, or contact the maintainer via GitHub.
- Vintage systems and bus adapters are not hardened security products; treat them accordingly.
